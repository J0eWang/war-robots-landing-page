Slicing Website - War Robots Official Landing Page



Proyek ini adalah tugas **slicing** halaman utama (Landing Page) dari website resmi War Robots yang dibangun menggunakan HTML, Plain CSS, dan Vanilla JavaScript (DOM).



1\. Responsif: Tampilan dapat menyesuaikan layar HP (Mobile), Tablet, hingga Komputer Desktop.

2\. Hero Section dengan Background: Memiliki latar belakang bertema sci-fi/mecha dengan teks overlay yang jelas.

3\. Interactive Robot Showcase (DOM): Pengguna dapat memilih jenis robot (Destrier, Cossack, Griffin) di mana teks deskripsi dan gambar robot akan diperbarui secara dinamis menggunakan manipulasi DOM.

4\. Simulasi Download via DOM: Penanganan interaksi tombol unduh platform tanpa mereload halaman.
